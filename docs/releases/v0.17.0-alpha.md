# Goanna v0.17.0-alpha

A new menu built around Continue, finding games on your own network, and
a clear screen when a server drops you. On DorfCraft servers the overseer
now shows its lists as tables, and creatures get planned footsteps and new
kinds of motion. This release is Linux only; there is no Windows build.

## Menu

- **Continue is the main screen's first button**, named with the world you
  played last and its game, and starts it again with the same settings.
  With no world yet it is New world. Everything else on the main screen is
  quiet, and Content, Local players, About and Quit sit in a quieter row.
- **Your worlds** is a table of world, game and last played, newest first,
  with the chosen world's game, mods, play mode and hosting beside it and
  Play in the footer. Change options and Delete world (which asks first)
  are there too. Start Game is gone; its options are on these screens.
- **New world** takes four steps (game, name and seed, options, hosting),
  each with a default, so Next, Next, Next and Create makes a world.
  Hosting is off unless you tick Open to LAN. The seed is new: empty means
  a new map each time.
- **Join a game** puts this network and the servers you joined before
  first. The public list is a searchable table of server, game, players
  and ping behind Browse public servers, and a typed address and the
  materials and shader choices are folded away.
- **Settings** keeps the graphics profile, the main sliders and switches,
  and accessibility on its front page. The shader pack and every render
  switch are under Advanced graphics; nothing was removed.
- **Content** is one table of games, mods and texture packs, with the
  worlds using each, filterable by kind.

## Joining

- **Scan local network** on Join a game lists the Luanti servers on your own
  network. Luanti servers do not announce themselves on a LAN, so Goanna
  asks each address on this computer's private /24 networks, ports 30000 to
  30005, with the packet a client opens a connection with, and closes each
  answer at once. It runs only when pressed. Pick a server to fill in the
  address.
- **A dropped game now says so.** When a server crashes, kicks you or shuts
  down mid game, the world is covered by "Disconnected from the server"
  with the server's message and a Back to the menu button. Before, the
  world stayed up with nobody answering: blocks broke locally and nothing
  else moved.
- **Back returns to Join a game** after a refused or dropped join, with the
  reason shown, and the password field focused after a wrong password.
  It used to open the main menu.

## Director

- **The director can move a stuck player**, when the operator sets
  `goanna_director_move_players = true`: to a point (landing on clear
  ground at or within two nodes of it) or beside another player, with the
  reason told to the player, at most once every five seconds, and never a
  player who opted out or to one. Undo moves them back. The join notice
  says when this is on. MCP tool: `director_move_player`.
- **The menu copies the game master command.** New world's Options step
  and a world's Change options have Copy
  Claude Code command and Copy MCP settings, filled in for the chosen
  world. Goanna still runs no game master itself: players are told a
  language model is acting as game master, so one runs only while a model
  app has started it.

## Hosting

- **A local server ends with its Goanna.** When Goanna quits, crashes or
  is killed, the Luanti server it started is sent SIGTERM within about a
  second, saves and shuts down, freeing its port; anything left after 30
  seconds is killed. Run on Linux with the Flathub Luanti and the bundled
  server; macOS takes the same path but has not been tried. On Windows a
  server whose Goanna crashed or was killed still keeps running.
- **A local server that fails to start now says why.** Starting the Kindred
  preview from 0.16.0 stopped at once with an empty log: the Flathub
  Luanti could not open its log file in the release folder. The server's
  output now goes to the log by another route, and a failed start shows
  the log's path as a link.
- **Open to LAN gives this computer's addresses**, and repeats them in the
  host's chat. Players who join get interact and shout, not the single
  player privileges.
- **An installed game modpack**, such as Kindred Holdfast, is offered in
  the game list as itself.

## Overseer (DorfCraft)

- **Lists are tables.** People, Supplies, Plans, Houses and the workshop
  picker each cover the map with one sortable, searchable table, with the
  chosen row's detail and its one main action beside it. Greyed rows say
  what they need. Long lists of variants (every wood, every colour of
  wool) are grouped under one row that opens with a click, Enter or the
  right arrow. A server that sends no tables keeps the older side panel.
- **The rail is grouped** under Plan and Fortress, fits at 1280 by 720
  and scrolls sideways at large text rather than wrapping words. It shows
  only the sections the server allows; locked ones are greyed with how to
  unlock them.
- **One View menu** holds the overlays and Plan marks in the world, in
  place of nine footer toggles. A task tool opens the overseer on its own
  section with only its own overlays, the first one on.
- **One rune per plan** on the map, drawn flat so it always shows, and the
  night watch marks are named in the legend and kept to Defence.
- Screens stay readable at 200 percent text.

## Creatures and combat (DorfCraft)

These need a server that sends the matching plans, so far DorfCraft.

- **Planned footsteps.** Bodies with a stroke plan plant their feet in the
  world and step when they fall behind, rather than sliding with the walk
  clip. One live melee trial landed 58 steps with no missing foothold;
  nobody has watched it yet.
- **Weapon families.** A stroke is posed with the family for the weapon
  the server names (sword now, others as they are authored). Checked
  offline only.
- Checked offline only, not yet against a server: four-legged bodies that
  walk and trot with each girdle following its own feet, hands and feet on
  ladders and ledges, fliers that beat, bank, tuck and land from the
  server's air state, animals' natural attacks blended by where they aim,
  and looping work tasks with the feet planted.
- **Distant combatants cost less.** Near bodies are posed in full, further
  ones 15 times a second, and beyond 48 nodes the game's own clip, with a
  quarter second fade so nothing pops. Measured offline; no crowd has been
  run live.

## World

- **DorfCraft tree branches are round rods** that meet node to node, in
  place of the stock boxes. Collision and selection are unchanged.
  Seen against Luanti 5.17.0 with Mineclonia and DorfCraft.
- **Wool, carpet and bedding no longer glow in dark rooms.** Their rim
  light took every lamp in range and the sun through walls and roofs; it
  now falls off with distance and shadow as other light does.
- **Server forms:** a table scrolls to its chosen row, and tree tables open
  their rows to the depth Luanti does.

## Accessibility

- **Spoken dialogue.** Character dialogue a game marks for speech is read
  through the system voice, with the speaker's name, even when Read aloud
  is off. It has its own switch, Spoken dialogue, under Audio, and is on
  by default.

## Building from source

- **The README's quick start now imports the project once** with
  `godot --headless --import --path project`. Without it a fresh clone
  stops with `Could not find type "GoannaClient"`, which can look like a
  graphics driver fault.

## Known limits

- No Windows build in this release. Windows clients are not offered the
  update and stay on 0.15.1.
- On Windows, a local server whose Goanna crashed or was killed keeps
  running.
- A wrong password still costs the world's loading time before the
  server's answer arrives.

Goanna is independent of the Luanti project.
