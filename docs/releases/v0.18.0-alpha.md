# Goanna v0.18.0-alpha

The player's own body now moves with the controls, not a moment after
them, and the client walks the world more as the stock client does: it
collides with boats and carts, eases up a step, and takes a full block
step where a server grants one. The keyboard gains a drop key and a
screen for changing keys, and the main screen says which version this
is. This release is Linux only; there is no Windows build.

Most of this was checked headless or by tests, and each entry says how.
Little of it has been played on a screen.

## Menu and controls

- **The main screen shows the version.** Its last line reads "Goanna"
  and the installed version, or "source checkout". Before, the version
  was only on About. The menu layout test passes headless; not looked
  at on a screen.
- **Q drops.** The keyboard has a drop key, Q as in Luanti: it drops the
  wielded stack, or one item with Shift held, as the same inventory
  action the stock client sends. Only the controller could drop before.
  Seen on 6 November 2026 against a Luanti 5.18.0 server running
  Mineclonia with DorfCraft's mods, from Godot 4.5.1: Shift and Q took
  one of five cobblestone, Q alone the whole stack.
- **Key bindings.** Settings has a Key bindings screen (a tab in the
  pause menu's settings): every keyboard control in a table, changed by
  choosing it and pressing the new key. A key another control has is
  refused with the reason, Reset to defaults puts every key back, and
  the controls that cannot be changed (digging and placing, Escape,
  Ctrl+B) are listed greyed. Keys are saved under Luanti's own
  `keymap_*` names and key format.
- **Shift and double click moves every stack of an item.** A shift
  double click in an inventory sends one ordinary move for each other
  stack of the item the shift click moved, as if each were shift
  clicked in turn. The server checks each as before, on any server. It
  matters most where blocks stack one to a slot, as on DorfCraft
  servers.
- **Camera.** Moving the mouse with Alt held no longer turns the view in
  first person by accident, Alt and the wheel still return the camera,
  and looking up and down is the right way round in the front view.
  Checked by offline tests of the input handler.
- **No attack while eating.** Using food or drink no longer swings the
  hand or starts an attack, and attacking waits for the button to be
  let go after a meal. The third person body stays drawn when the
  camera is pushed close by a wall. Headless checks only (11 of input,
  31 of the camera); eating has not been watched on a screen.

## Moving through the world

- **The player collides with physical objects** as the stock client
  does: an object whose properties set both `physical` and
  `collide_with_objects` blocks the player, can be stepped onto when
  lower than the step height, and can be stood on. Before, Goanna
  walked through boats, carts and every other physical object. An
  object with `collide_with_objects = false` does not block, and
  standing on a moving object does not carry the player. Seen on 6
  November 2026 against a Luanti 5.18.0 server running Mineclonia:
  walking into a one node entity stopped 0.012 nodes short of its face,
  and the player stood on its top for eight seconds. Attached physical
  objects do not collide yet.
- **A server's step height is used.** The client reads the local
  player's step height from the server instead of assuming 0.6 nodes. A
  grant above one node climbs a full block from the ground without a
  jump; jumping, and autojump on ordinary servers, are unchanged. A
  headless client on Luanti 5.18.0 with Mineclonia crossed a full block
  ledge with no jump and stopped at a two block wall.
- **A step up eases on screen** as the stock client's camera eases it:
  the eye and the player's own body rise over about 0.13 seconds
  instead of in one frame. Falls, jumps and server moves still show at
  once, and the position sent to the server is unchanged. Sampled
  headless at 60 frames a second on 8 November 2026: a whole block rose
  0.32 nodes in the first frame and was within 5% of the top after
  0.133 s. Nobody has played it on a screen.
- **A tree cut is not restarted** when the server sends a new tool time
  part way through. Checked by an offline test of the dig clock.

## Drawing

- **Relief no longer speckles far from the world's origin.** Ten
  thousand nodes out, hollows in parallax surfaces near the camera drew
  as grainy speckle, because the shader worked from world positions
  too large for their precision. It now works in view space. Checked on
  lavapipe at (-9821, 75, -2273) and at the origin, where the old and
  new frames match to 0.01% of pixels.
- **Nametags are about the stock client's size** and fade out past 24
  metres over 4, instead of a fixed 7% of the window height at any
  distance, which piled a village's names into a heap. A nametag's own
  font size and its background colour (drawn as the outline) are used.
  Built only: no frame was rendered.
- **Attached objects turn as the stock client turns them.** A turn
  about more than one axis was mirrored, so a held item could point the
  wrong way. Six turns are checked against Irrlicht's own matrix.
- **Cube furniture is lit with the world** like other nodes, without the
  extra fill it had beside real lights.

## Creatures and combat (DorfCraft)

For servers running DorfCraft's Kindred mods. Other servers see no
change from these.

- **The player's own body follows the controls at once.** It kept
  swinging 0.6 to 2.4 seconds after digging stopped, and a stroke's
  strike waited for the server. The body's idle, walk and dig clips now
  play from the local controls, and a released stroke carries on to its
  strike locally until the server's answer takes over. Nothing extra is
  sent, and the server still judges contact. Headless on Luanti 5.18
  with Mineclonia: release to stop and to strike took 0.31 to 0.36 s,
  against 0.4 to 1.9 s before.
- **A melee draw starts on the press** for a weapon the server marks,
  and is withdrawn on release, on the server's say or after a timeout.
  A blow that lands follows the server's contact clock into a hard
  withdrawal or a follow through. Damage and defence are never
  predicted. Native checks pass; not yet seen connected.
- **A stroke's aim follows the pull's furthest point**, as the server
  now takes it, so the preview shows the stroke the server strikes. A
  held weapon follows the accepted elevation without an extra punch
  swing.
- **Wounds are cut on the client.** A server sent each wound as a whole
  new model to every viewer, 1.4 MB for a person. It now sends a form
  once and each body's damage state, and the client builds the wounded
  mesh, checked byte for byte against the server's. Seen on lavapipe
  against Luanti 5.18.0 with Mineclonia: a battle's wounded people and
  water buffalo drew from client cut models. A model that fails to load
  is no longer retried every frame.
- **Sneaking lowers the body**, by the depth the server declares, so
  the first person camera no longer sits in its own chest. Checked by
  the steps test only; not yet rendered.
- **Sleepers keep their authored pose**: foot planning lets go of a
  body playing a rest clip.

## Known limits

- No Windows build in this release. Windows clients are not offered the
  update and stay on 0.15.1.
- On Windows, a local server whose Goanna crashed or was killed keeps
  running.
- A wrong password still costs the world's loading time before the
  server's answer arrives.
- Attached physical objects do not block the player, and standing on a
  moving object does not carry it.

Goanna is independent of the Luanti project.
