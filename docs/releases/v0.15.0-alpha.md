# Goanna v0.15.0-alpha

Joining a server you have played on before no longer downloads its media
again, and shader packs draw their own skies and keep their full colour
range. Distant terrain does less of its setup work while you play.

## Joining

- **Server media is kept between visits.** Textures, sounds and models a
  server sends are kept in a cache, checked, and used again the next
  time, through Luanti's own file cache. Only missing, damaged or changed
  files are downloaded. On a local devtest server the first join
  downloaded 447 files and a reconnect downloaded none. If the cache
  cannot be written, joining still works as before.
- **Clearer loading.** The loading screen now says whether it is reading
  the cache, downloading, or preparing the world, rather than calling all
  three downloading.
- **A place to ask for help.** The README links the
  [Goanna Discord server](https://discord.gg/asDVADMc5N).

## Shader packs

Still experimental, as in 0.14.0. Everything in this section was checked
against a Minecraft Java 26.2 server through the BridgeTest proxy, not yet
against a Luanti server, on Godot 4.5.1.

- **Pack skies.** A pack's own sky, sun and moon programs are drawn,
  instead of Goanna's sky. Eclipse's sky was observed with no shader
  errors. Custom sky geometry and sunset geometry are not supported yet.
- **Full colour range.** Lighting is handed to the pack's later passes
  without being clipped or gamma converted first, and packed material
  data passes through exactly. Blended material values remain
  approximate.
- **Light as packs expect it.** Packs receive block and sky light on the
  linear scale they are written for, and eye brightness measured at the
  camera, smoothed as the pack asks.
- **Ambient occlusion and face shading as Iris does them.** Packs'
  `separateAo` and ambient occlusion level settings are honoured, and the
  old per face shading is off by default.
- **Glass and ice** use the pack's translucent program. Against Minecraft,
  the error in glass colour fell from 77 levels to 21. Ice has not been
  checked.
- **A missing sky input reads white, not black,** matching what packs
  observe in Minecraft.
- **Pack terrain textures are filtered as Minecraft filters them,**
  sharp texels with blended mipmaps, which removes excess shimmer in the
  distance. Goanna's own terrain is unchanged.

## Performance

- **Fewer first sight stalls.** Materials for every kind of block, near and
  far, are now prepared a little at a time from the moment the game's
  definitions arrive, rather than the first time each one comes into
  view.
- **Distant terrain is built off the main thread.** The work of turning a
  finished distant region into a mesh moves to the worker threads, and its
  upload to the graphics card is spread over several frames, with the old
  terrain kept on screen until its replacement is complete.

These target the stutter while distant terrain streams in. They were
checked for correctness on a local Luanti 5.17.0 server running Mineclonia
with Godot 4.5.1. **No frame time improvement has been measured yet.**
Preparing every material up front may use a little more memory.

## Fixes

- **A rare problem while joining.** Water effects could read block names
  while the server was still sending block definitions. They now wait
  until the definitions are ready.
- **No more errors from update checks** for optional material packs that
  are not installed.

## Known limits

Not run on Windows; the Windows build is compiled and packaged only. Not
tested on a Steam Deck in this release.

Goanna is independent of the Luanti project.
