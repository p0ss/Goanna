# History

Dated logs and investigations. Each entry describes the code as it was on
its date, says what it was checked against, and is kept as written, so a
later entry or the code wins where they disagree. For how things work now,
read the [systems](../systems/index.md) pages; for plans, the
[design](../design/index.md) pages.

## Logs

- [Development log](development-log.md): the project wide record, release
  by release, newest first. It began as the log in `PLAN.md`.
- [Far rendering log](far-rendering-log.md): each rung of the far field,
  its measurements and its faults, oldest first.
- [Director log](director-log.md): what each director test ran on and
  showed.
- [Materials log](materials-log.md): material investigations and
  measurements.
- [Overseer log](overseer-log.md): the overseer camera's verification
  record, and the client fixes DorfCraft's playtests turned up.

## Investigations and checkpoints

- [Material calibration](material-calibration.md): the offline material

  looking terrain, relief and smoothness.
- [Performance inventory](performance-inventory.md): the source audit of
  27 September 2026 that led to the render feature switches and the
  Lowest tier.
- [Default look checkpoint](default-look.md): a work in progress lighting

## Measurements

Reports, captures and the harnesses that made them live in `docs/perf/`,
one folder per study, named with its date. They are kept in the repository
beside the scripts that reference them and are not part of this site;
browse them [on GitHub](https://github.com/p0ss/Goanna/tree/main/docs/perf).
